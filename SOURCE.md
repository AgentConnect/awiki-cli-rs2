# AWiki CLI S2 Source

The canonical source repository is:

https://github.com/AgentConnect/awiki-cli-rs2

Official release packages replace this file with release-specific information
that identifies the exact version, immutable commit, source archive, and build
instructions corresponding to the packaged binary.

For a source checkout, the checkout itself is the source. Use `git rev-parse
HEAD` to identify its exact revision and follow [`docs/development.md`](docs/development.md)
for build instructions.
