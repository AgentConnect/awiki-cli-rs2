# File Size Exceptions

Rust source files should stay at or below 1200 non-generated lines by default. Exceptions require a corresponding oversized Go source file and a documented reason. A genuinely special file may be relaxed up to about 5000 lines when justified, but exception use must remain rare rather than becoming the normal module shape.

| Rust path | Rust lines | Go path | Go lines | Reason |
| --- | ---: | --- | ---: | --- |
| `crates/awiki-cli/src/runtime/listener_supervisor_run.rs` | 1771 | `awiki-cli/internal/runtime/listener/server.go` | 1802 | Foreground listener execution currently mirrors the oversized Go supervisor file for traceable 1:1 translation of run/service-run startup, bridge ownership, WebSocket session loops, secure notification normalization, local secure ACK recovery, queued local notification ownership/flush, queued secure outbox flushing, secure backlog replay, direct/group incoming contact lookup wiring, and bridge-created session bootstrap waiting. This is an intentional translation-time exception; splitting this runtime owner into smaller Rust files is a later optimization/refactor task, not mixed into the parity slice. New helper behavior should stay in smaller modules where practical; secure replay wiring reuses existing helper modules instead of carrying duplicate inline parsing/scanning logic, bridge-created sessions reuse the Supervisor host-notify sink and local-notification queue through small helpers, bridge bootstrap waiting uses `listener_bridge_runtime.rs` for one-shot signal/wait semantics rather than growing this file with another state machine, and local notification queue/flush primitives remain in `listener_local_notifications.rs` and `listener_local_notification_flush.rs`. |
