# Parity Matrix

Status values: `not_started`, `in_progress`, `ported`, `unit_verified`, `system_verified`, `deferred_with_reason`.

Dependency constraint: Rust modules should prefer pure Rust, cross-platform
dependencies. SQLite, SSL/TLS, crypto, and platform integration choices must
avoid host system libraries by default. SQLite currently has a user-approved
exception: `rusqlite + bundled` compiles SQLite into the CLI binary for runtime
portability. Any exception must be recorded here and in
`docs/dependency-decisions.md` with the reason and verification evidence.
TLS should use Rustls-first stacks. OpenSSL is not preferred even when bundled;
bundled OpenSSL is still a native dependency exception and needs explicit
parity evidence before adoption.
The recommended TLS default is `rustls`; OpenSSL/`native-tls` and OpenSSL
`vendored`/bundled feature paths must not be introduced before Rustls-backed
options have failed a documented parity requirement.
Future HTTPS/WebSocket lanes should begin with Rustls-backed clients and verify
the dependency tree stays free of OpenSSL/`native-tls`; bundled OpenSSL is not a
preferred fallback.

Parallel execution constraint: Native Agents may be used for independent
module/file slices when that improves throughput. Any code-writing Native Agent
must use GPT-5.5 with xhigh reasoning and a bounded, non-overlapping write
scope; read-only Native Agents may use lighter settings.
